#OceanX Grocery Delivery App

A basic dummy grocery application built using Kotlin and XML for the OceanX internship assignment.

#Features

- Login using Phone Number + Fake OTP
- Product Listing Screen
- RecyclerView with Grid Layout
- Add To Cart Functionality
- Cart Screen
- Checkout Screen
- Order Success Screen
- Clean UI Design

#Screens

- Login Screen
- Home Screen
- Cart Screen
- Checkout Screen
- Order Success Screen


#Tech Stack

- Kotlin
- XML Layouts
- RecyclerView
- ViewBinding
- Android Studio
